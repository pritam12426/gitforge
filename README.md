# gitforge

**gitforge** is a fast, feature-rich Git MCP (Model Context Protocol) server 
written in Rust. It bridges AI assistants like Claude to your Git repositories, 
exposing a comprehensive set of version control operations — commit history, 
diffing, branching, blame, merge analysis, and more — through a clean, 
async-first architecture powered by `git2-rs` (libgit2 bindings).

Built to be the feature-complete alternative to lightweight scripting-based 
Git MCP servers, with a focus on performance, safety, and extensibility.
